作业1：搭建环境、两种方式运行 Hello World、程序结构与常用寄存器
================================================================

一、作业1 要做的三件事
----------------------------------------------------------------
1. 搭建好 DOSBox + MASM + LINK + DEBUG 的汇编环境；
2. 用两种方式在屏幕上显示 Hello, World!：
     · 常规方式：调用 DOS 中断 INT 21H（程序 hello1.asm）
     · 直接写显存：把字符直接写进 B800H 段的显存（hello2.asm）
3. 通过这两个小程序，理解程序的固定结构和常用寄存器的作用。


二、两种显示方式的区别
----------------------------------------------------------------
1. 常规方式（hello1.asm）
     把字符串放在数据段，用 INT 21H 的 09H 功能输出：
         DS:DX 指向字符串，字符串必须以 '$' 结尾；
     DOS 负责把字符送到屏幕，程序不用关心显存地址。

2. 直接写显存（hello2.asm）
     彩色文本模式的显示缓冲区在 B800H 段，屏幕 80x25：
     每个字符占 2 个字节 —— ASCII 码 + 显示属性（07H = 黑底白字）。
     第 12 行第 33 列的偏移 = (12*80 + 33) * 2 = 07C2H。
     程序把 ES 指向 B800H，再用 ES:[DI] 直接写，绕过了 DOS/BIOS。

     对比：常规方式"说一句话让 DOS 去办"，
           直接写显存"自己动手把数据摆到屏幕对应的内存里"。


三、程序的基本结构（两个程序都遵守）
----------------------------------------------------------------
    stack segment stack       ; ① 栈段：程序运行时的栈空间
        db 128 dup(?)
    stack ends

    data segment              ; ② 数据段：存放要用的数据（字符串等）
        msg db '...'
    data ends

    code segment              ; ③ 代码段：真正的指令
        assume cs:code, ds:data, ss:stack
    start:                    ; ④ 程序入口
        mov ax, data          ;    初始化 DS（段地址不能直接送立即数）
        mov ds, ax
        ...
        mov ax, 4c00h         ; ⑤ 返回 DOS
        int 21h
    code ends
        end start             ; 告诉汇编器：入口是 start

几点必须记住：
  · assume 只是"告诉汇编器"哪个段用哪个段寄存器；
    运行时真正装段地址，还是要 mov ax,段名 / mov ds,ax。
  · 程序最后要用 INT 21H 的 4CH 功能返回 DOS，
    否则 CPU 会继续往下执行，出现莫名其妙的死机或乱跑。
  · end start 里的 start 必须和入口标号一致。


四、常用寄存器及其作用
----------------------------------------------------------------
【通用寄存器（16 位，都可以拆成高 8 位 / 低 8 位）】
  AX (AH,AL)   累加器，运算和输入输出最常用；INT 21H 的返回值常在 AL/AX
  BX (BH,BL)   基址寄存器，常用来存放内存地址或临时数据
  CX (CH,CL)   计数器，LOOP 指令固定使用 CX（CX 减 1，不为 0 就跳）
  DX (DH,DL)   数据寄存器，INT 21H 输出字符用 DL，字符串地址用 DX

【指针和变址寄存器】
  SP           栈顶指针，PUSH/POP、CALL/RET 都靠它
  BP           基址指针，常用于访问栈上的参数和局部变量
  SI / DI      源变址 / 目的变址，常配合 DS:SI、ES:DI 做数据搬运

【段寄存器】
  CS           代码段，CS:IP 指向下一条要执行的指令
  DS           数据段，DS:DX、DS:SI 常用来访问数据
  SS           栈段，SS:SP 指向栈顶
  ES           附加段，hello2.asm 里用它指向显存段 B800H

【指令指针和标志】
  IP           指令指针，和 CS 一起决定下一条指令的地址
  FLAGS        标志寄存器，条件跳转看的就是它：
                 ZF 结果为零、CF 进位/借位、SF 符号、OF 溢出


五、这两个程序用到的指令
----------------------------------------------------------------
  MOV   传送数据（寄存器之间、寄存器和内存之间、立即数到寄存器/内存）
  INT   调用中断（21H 是 DOS 功能调用）
  INC   加 1
  ADD   相加
  LOOP  CX 减 1，不为 0 就跳转
  LEA   取地址（本作业用 offset 代替，效果类似）


六、怎么运行
----------------------------------------------------------------
   D:\> masm hello1.asm;
   D:\> link hello1.obj;
   D:\> hello1
   Hello, World!

   D:\> masm hello2.asm;
   D:\> link hello2.obj;
   D:\> hello2
   （屏幕第 12 行中间出现 Hello, World!，因为程序直接写显存，
     所以用 > 重定向是看不到的，必须看屏幕）

   验证直接写显存确实生效：运行完 hello2 后进入 DEBUG，
       D:\> debug
       -d b800:07c2 l 1a
   可以看到 48 65 6C 6C 6F ... 和 07 交替出现，
   48='H'、65='e'、6C='l' ...，07 就是黑底白字的属性。
