作业3  第3小题：用 C 语言实现求和后察看反汇编代码并加注释
================================================================

环境：DOSBox 0.74 + Turbo C++ 3.00（16 位 DOS 编译器）
源文件：sum3.c        可执行文件：sum3.exe


一、C 源程序（sum3.c）
----------------------------------------------------------------

    #include <stdio.h>

    int main(void)
    {
        int i, sum = 0;

        for (i = 1; i <= 100; i++)
            sum += i;

        printf("%d\n", sum);
        return 0;
    }


二、编译、运行和反汇编的命令
----------------------------------------------------------------

1) 编译链接：

    D:\> path d:\tc\bin
    D:\> tcc -Id:\tc\include -Ld:\tc\lib sum3.c

2) 运行（输出 5050）：

    D:\> sum3
    5050

3) 反汇编：

    D:\> debug sum3.exe
    -u 0 C00                 （从代码段偏移 0 反汇编到 C00H）
    -q

   程序装入后代码段定位在 076C，所以地址写成 076C:xxxx 的形式
   （这个段号每次运行都可能不同，不影响阅读）。


三、反汇编代码（main 函数部分）逐行注释
----------------------------------------------------------------

                        ; ===== 函数序言：保存用到的寄存器 =====
076C:0291 55        PUSH BP                  ; 保存调用者的 BP
076C:0292 8BEC      MOV  BP,SP               ; 建立本函数的栈帧
076C:0294 56        PUSH SI                  ; 保存 SI —— 后面要拿它当变量 i
076C:0295 57        PUSH DI                  ; 保存 DI —— 后面要拿它当变量 sum

                        ; ===== for 的初始化 =====

076C:0298 BE0100    MOV  SI,0001             ; i = 1

                        ; ===== 循环体：sum += i，然后 i++ =====
076C:029D 03FE      ADD  DI,SI               ; sum = sum + i

                        ; ===== 循环条件：i <= 100 ? =====

076C:02A3 7EF8      JLE  029D                ; i <= 100 就回到循环体

076C:02AD 59        POP  CX                  ; 调用者清理栈上的参数
076C:02AE 59        POP  CX

076C:02B4 5E        POP  SI                  ; 恢复 SI
076C:02B5 5D        POP  BP                  ; 恢复 BP

四、C 语句和汇编指令的对应关系（小结）
----------------------------------------------------------------

1) 局部变量 i 和 sum
     这里有个很有意思的地方：编译器**没有把它们放在栈上**，
     而是直接分配给了 SI（i）和 DI（sum）。
     因为这两个变量只在函数内部使用、没有取地址，
     放寄存器比放内存快得多。这就是"编译器会做优化"。
     （对比：上一个 ascii3 的例子里，i 是放在 [BP-02] 栈上的。）

2) for (i = 1; i <= 100; i++)
     初始化   XOR DI,DI（sum=0） + MOV SI,1（i=1）
     条件     CMP SI,64H + JLE（有符号"小于等于"用 JLE）
     循环体   ADD DI,SI
     自增     INC SI
     并且编译器先把 JMP 放到条件处，先判断再进循环体，
     和 C 的 for 语义完全一致。

3) sum += i
     就是一条 ADD DI,SI —— 累加器在寄存器里，根本不用访问内存。

4) printf("%d\n", sum)
     参数从右往左压栈：先 PUSH sum，再 PUSH 格式串的偏移；
     CALL printf 之后由调用者 POP CX 两次清理参数。
     "把整数变成十进制字符串"这件事由库函数完成，
     而我们手写的汇编版是自己用"除 10 取余"做的。

5) return 0
     XOR AX,AX，返回值放在 AX 里。

6) 函数序言 / 尾声
     序言：PUSH BP / MOV BP,SP / 保存用到的寄存器
     尾声：恢复寄存器 / POP BP / RET
     注意这里没有 SUB SP —— 因为局部变量都放进了寄存器，
     不需要在栈上留空间。


五、和手写汇编版（第1、2小题）的对比
----------------------------------------------------------------

· 手写版：自己决定用 CX 计数、AX 累加，循环 100 次得到 5050；
  打印时自己用"反复除以 10、余数压栈再倒序输出"把二进制值变成十进制。
· C 版：编译器把 i、sum 放进 SI、DI，循环体只有 ADD 和 INC 两条；
  输出交给 printf，进制转换的细节藏在库函数里。
· 结论：同样的求和，汇编要自己管寄存器、计数、进制转换；
  C 只写逻辑，剩下的交给编译器和库。看反汇编就是看"编译器替你做了什么"。
