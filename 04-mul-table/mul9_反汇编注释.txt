作业4  第3小题：九九乘法表 C 版本的编译结果与反汇编注释
================================================================

环境：DOSBox 0.74 + Turbo C++ 3.00（16 位 DOS 编译器）
C 源文件：mul9.c        可执行文件：mul9c.exe（与汇编版 mul9.exe 区分）


一、C 源程序（mul9.c）
----------------------------------------------------------------

    #include <stdio.h>

    int main(void)
    {
        int i, j;

        printf("The 9mul9 table:\n");

        for (i = 9; i >= 1; i--) {
            for (j = 1; j <= i; j++) {
                printf("%d*%d=%d", i, j, i * j);
                if (j != i) {
                    putchar(' ');
                    putchar(' ');
                    putchar(' ');
                    if (i * j < 10)
                        putchar(' ');
                }
            }
            putchar('\n');
        }

        return 0;
    }

四、要点小结
----------------------------------------------------------------
1) 双重循环在汇编里就是"两套计数器 + 两套条件跳转"：
     外层 i：SI，初始化 9，每轮 DEC，条件 CMP SI,1 / JL 结束；
     内层 j：DI，初始化 1，每轮 INC，条件 CMP DI,SI / JG 结束。
   编译器先把 JMP 放到条件判断处，做到"先判断、后执行"，和 C 的 for 语义一致。

2) i * j 用的是 IMUL（有符号乘法）：
     它把 AX 和操作数相乘，结果放在 DX:AX。
     这里乘积最大 81，所以只用 AX 就够；如果是大数就要连 DX 一起看。

3) printf 的参数从右往左压栈：
     先压 i*j，再压 j、i，最后压格式串；调用完 ADD SP,8 由调用者清理 4 个参数。
   这和 C 的 cdecl 调用约定完全一致。

4) putchar(' ') 每一句都展开成一大段：
     快路径直接写 stdout 缓冲区，缓冲区满才 CALL __fputc。
   所以 C 里 4 行 putchar，汇编里是几十条指令——这也是"看反汇编"的价值。

5) 返回值 0 用 XOR AX,AX，序言/尾声只保存实际用到的 SI、DI、BP。
